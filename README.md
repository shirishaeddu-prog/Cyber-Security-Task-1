 Task 1: Scan Local Network for Open Ports

Objective
To identify open ports on a local device/network and understand network service exposure.

Tool Used
- Python
- Pydroid 3

 Description
This Python program checks commonly used TCP ports on a local IP address and displays whether each port is OPEN or CLOSED.

Output
The program displays the scanning result for the entered local IP address.

 Security Note
The scanner is intended for authorized devices and networks only.

Conclusion
This task provides basic knowledge of network ports, services, and network security.
